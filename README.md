# 🛒 DigiKala Data Analysis

A Python-based **Exploratory Data Analysis (EDA)** project that analyzes product data from DigiKala, one of the largest e-commerce platforms in the Middle East. The project uses statistical analysis and data visualization techniques to uncover insights into product characteristics, pricing, customer ratings, and other key attributes.

---

# 📖 Overview

E-commerce platforms generate large volumes of product data that can be analyzed to understand pricing strategies, customer preferences, and product trends.

This project demonstrates how Python can be used to clean, explore, and visualize product data from DigiKala. Through exploratory data analysis, the project reveals patterns and relationships that support data-driven decision making.

---

# ✨ Features

* Import and preprocess DigiKala product data
* Clean and prepare the dataset
* Perform descriptive statistical analysis
* Explore numerical and categorical variables
* Analyze product prices and ratings
* Generate informative visualizations
* Identify patterns, trends, and potential outliers

# 🚀 Installation

Clone the repository:

```bash
git clone https://github.com/kasratookallo-svg/Digi_Kala_Data_Analysis.git
```

Navigate to the project directory:

```bash
cd Digi_Kala_Data_Analysis
```

Install the required packages:

```bash
pip install -r requirements.txt
```

# ▶️ Usage

Open the Jupyter Notebook and execute the cells to:

1. Load the DigiKala dataset.
